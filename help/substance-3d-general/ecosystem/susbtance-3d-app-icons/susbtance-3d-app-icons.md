Les artistes qui souhaitent inclure les icônes des applications Substance 3D dans leurs illustrations publiées peuvent les télécharger ci-dessous. Les images utilisent le format du SVG, elles peuvent donc être utilisées à n’importe quelle échelle.

[Téléchargez un dossier zip contenant les versions couleur, noire et blanche des icônes de l’application Substance 3D.](../../assets/substance3d-icons.zip)
