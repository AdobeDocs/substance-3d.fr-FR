# contrôle de version d’un moteur de Substance

Les matériaux de Substance et les modèles créés dans un logiciel de Substance ne peuvent être utilisés que dans des applications prenant en charge la même version ou une version plus récente de la Substance Engine

Reportez-vous aux tableaux ci-dessous pour savoir si un matériau de Substance ou un modèle procédural de Substance est utilisable avec la version actuelle de votre logiciel. Les tableaux ne répertorient pas toutes les versions pour chaque application, mais uniquement celles avec une mise à jour. Si aucune version n’est spécifiée, la version précédente de la Substance Engine est utilisée.

>[!NOTE]
>
> Pour savoir quel moteur de Substance, baker ou version de déplié automatique est utilisé dans vos applications installées, utilisez **Aide > À propos**, puis utilisez le menu déroulant **Informations supplémentaires** pour obtenir une vue d&#39;ensemble complète.
