# Versions héritées

Les versions héritées sont des applications Substance 3D compatibles avec le système d’activation de fichiers par clé de licence hérité en place avant la transition vers l’activation de compte d’Adobe. Ces versions ne sont pas compatibles avec les licences achetées via votre compte Adobe ou votre compte Steam.

Pour télécharger les anciennes versions de Substance 3D Painter et Designer, rendez-vous à l’adresse suivante :\
<https://www.substance3d.com/legacy-builds/>
