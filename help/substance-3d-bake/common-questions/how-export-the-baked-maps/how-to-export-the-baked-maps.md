# Comment exporter les cartes cuites ?

>[!WARNING]
>
> **Question**
> 
> Comment puis-je exporter les textures que j&#39;ai cuites dans mon mesh pour les utiliser dans une autre application ?

>[!NOTE]
>
> **Solution : Concepteur de substance**
> 
> Les fichiers de sortie des boulangers doivent être situés à côté du graphique Substance où le maillage est lié. Cliquez avec le bouton droit et choisissez « explorer » pour afficher les fichiers dans la fenêtre Explorateur de l’application.

>[!NOTE]
>
> **Solution : Peintre De Substance**
> 
> Les fichiers de sortie des boulangers sont enregistrés dans le fichier de projet (\*.spp). Pour les exporter, vous pouvez effectuer l’une des opérations suivantes :
> 
> * Utilisez la boîte de dialogue **Fichier > Exporter les textures** et sélectionnez le paramètre d’exportation prédéfini « Mappages de maillage »
> * Cliquez avec le bouton droit de la souris sur une texture cuite dans l&#39;étagère et choisissez « Exporter ».

>[!NOTE]
>
> **Solution : Substance Automation Toolkit**
> 
> Les fichiers de sortie des Bakers sont enregistrés par défaut à côté du maillage. Le dossier de sortie peut être modifié à l’aide d’un argument spécifique dans la ligne de commande.
