# Pourquoi mon maillage est-il complètement noir après le baking ?

>[!WARNING]
>
> **Question**
> 
> Pourquoi mon maillage est-il complètement noir dans le viewport après que je viens de finir de baker en Substance Painter ?

>[!NOTE]
>
> **Explication**
> 
> Le viewport étant entièrement noir après le baking, c&#39;est parce que l&#39;une des textures bakées est également entièrement noire. Si la texture d’Ambient occlusion est noire, elle obscurcit tout l’éclairage dans le viewport, par exemple.

>[!NOTE]
>
> **Solution : Substance Painter**
> 
> Il existe deux solutions possibles :
> 
> * Corrigez votre configuration de baking pour éviter les textures noires. Voir : [La sortie Baker est entièrement noire ou vide](https://helpx.adobe.com/fr/substance-3d/unlisted/documentation/bake/baker-output-is-fully-black-159451835.html)
> * Supprimez la texture noire des [paramètres de Jeu de textures](https://experienceleague.adobe.com/fr/docs/substance-3d-painter/using/interface/texture-set/texture-set-settings).
