# Map height depuis le maillage

La carte d&#39;Height de mesh baker vous permet de créer une carte d&#39;height à partir d&#39;un maillage en poly élevé.**Disponible dans :**

* Painter
* Designer
* Automation Toolkit

## Paramètres

| *Paramètre* | *Description* |
| --- | --- |
| **&#x200B;**&#x200B;Normalisation&#x200B;**&#x200B;** | Définit la façon dont la plage de valeurs height doit être enregistrée dans la texture.Valeurs possibles :<ul data-preserve-html="true"><li data-preserve-html="true"><strong>Par rapport à la distance des rayons</strong> :</li><li data-preserve-html="true"><strong>Par rapport à un maillage poly faible (par carreau UV)</strong> (par défaut)</li><li data-preserve-html="true"><strong>Par rapport à la min/max (par carreau UV)</strong></li><li data-preserve-html="true"><strong>Manuel</strong></li></ul> |
| **Diviseur d&#39;échelle** | Définissez la valeur d’height à multiplier ou à diviser.Disponible uniquement lorsque la **normalisation** est définie sur **Manuel**. |
