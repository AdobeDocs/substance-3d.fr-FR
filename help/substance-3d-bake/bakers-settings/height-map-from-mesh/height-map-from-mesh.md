# Map height depuis le maillage

La carte de hauteur de mesh baker vous permet de créer une carte de hauteur à partir d&#39;un maillage poly élevé.**Disponible en :**

* Painter
* Designer
* Boîte à outils d’automatisation

## Paramètres

| *Paramètre* | *Description* |
| --- | --- |
| **&#x200B;**&#x200B;Normalisation&#x200B;**&#x200B;** | Définit la manière dont la plage de hauteur des valeurs doit être enregistrée dans la texture.Valeurs possibles :<ul data-preserve-html="true"><li data-preserve-html="true"><strong>Relatif à la distance des rayons</strong> :</li><li data-preserve-html="true"><strong>Par rapport à un maillage poly faible (par dalle UV)</strong> (par défaut)</li><li data-preserve-html="true"><strong>Relatif à Min/Max (par tuile UV)</strong></li><li data-preserve-html="true"><strong>Manuel</strong></li></ul> |
| **Diviseur d’échelle** | Définissez la quantité que les valeurs de hauteur doivent multiplier ou diviser.Disponible uniquement lorsque l’option **Normalisation** est définie sur **Manuel**. |
