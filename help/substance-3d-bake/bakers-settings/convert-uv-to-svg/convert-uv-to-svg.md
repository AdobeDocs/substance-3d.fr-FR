# Convertir UV en SVG

Le boulanger Convertir les UV en SVG transforme les UV de maillage à faible poly en fichier graphique vectoriel. Ce fichier graphique vectoriel peut être utilisé pour créer des masques.

**Disponible dans :**

* Substance Designer
* Substance Automation Toolkit

## Paramètres

| *Paramètre* | *Description* |
| --- | --- |
| **Remplissage** | Détermine la quantité de remplissage géométrique à ajouter aux formes SVG. |
| **Mode colorimétrique** | Définit la façon dont les formes du SVG doivent être colorées.Valeurs possibles :<ul data-preserve-html="true"><li data-preserve-html="true"><strong>Aléatoire :</strong> chaque coque UV est colorée par une couleur aléatoire.</li><li data-preserve-html="true"><strong>Décalage de teinte :</strong> chaque coque UV est colorée par une valeur de teinte unique.</li><li data-preserve-html="true"><strong>Niveaux de gris :</strong> chaque coque UV est colorée par une valeur de niveaux de gris unique.</li><li data-preserve-html="true"><strong>Couleur uniforme :</strong> toutes les coques UV sont colorées par une valeur de gris de 50 %.</li><li data-preserve-html="true"><strong>Couleur d&#39;ID de matériau</strong> : les coques UV sont colorées par la couleur du matériau définie dans la vue Scène.</li></ul> |
