# Convertir UV en SVG

Le baker Convert UV to SVG transforme les UV à faible maillage en un fichier graphique vectoriel. Ce fichier graphique vectoriel peut être utilisé pour créer des masques.

**Disponible dans :**

* Concepteur de substance
* Boîte à outils d&#39;automatisation des substances

## Paramètres

| *Paramètre* | *Description* |
| --- | --- |
| **Marge intérieure** | Contrôle la marge intérieure géométrique à ajouter aux formes SVG. |
| **Mode Couleur** | Définit la manière dont les formes SVG doivent être colorées.Valeurs possibles :<ul data-preserve-html="true"><li data-preserve-html="true"><strong>Aléatoire :</strong> chaque coque UV est colorée par une couleur aléatoire.</li><li data-preserve-html="true"><strong>Décalage de teinte :</strong> chaque coque UV est colorée par une valeur de teinte unique.</li><li data-preserve-html="true"><strong>Niveaux de gris :</strong> chaque coque UV est colorée par une valeur de niveaux de gris unique.</li><li data-preserve-html="true"><strong>Couleur uniforme :</strong> toutes les coques UV sont colorées par une valeur de gris de 50%.</li><li data-preserve-html="true"><strong>Couleur ID matière</strong> : les coques UV sont colorées par la couleur de matière définie dans la vue de la scène.</li></ul> |
