# Substance 3D Painter

![](../../../assets/sp-baking-button-access.png)

La fenêtre de baking est accessible via les [paramètres de Jeu de textures](https://experienceleague.adobe.com/fr/docs/substance-3d-painter/using/interface/texture-set/texture-set-settings). Cliquez sur le bouton intitulé « **Baking des Maps de maillage** » pour ouvrir la fenêtre de baking du projet actif.

## Vue d’ensemble

![](../../../assets/sp-ui-overview.png){width="400px"}

La fenêtre de baking est divisée en trois composants principaux.

### Liste baker

![](https://helpx-prod.scene7.com/is/image/HelpxProd/sp-baking-list?$png$&jpegSize=100&wid=150)

Plusieurs boutons sont disponibles en haut à gauche de la fenêtre.

En regard de ce bouton se trouve une case à cocher. Si elle est cochée, elle active ce baking pour le processus de baking. Les boutons qui ont une icône à côté de leur nom indiquent ceux qui ont besoin d&#39;un maillage high-poly. Cette icône affiche un avertissement s’il y a maintenant un niveau élevé de polyvalence disponible.

| *Bouton* | *Description* |
| --- | --- |
| **Commun** | Modifiez la vue des paramètres sur les [paramètres communs](../../../bakers-settings/common-parameters/common-parameters.md). |
| **Normal** | Changez la vue des paramètres en [Paramètres normaux](../../../bakers-settings/normal-map-from-mesh/normal-map-from-mesh.md). |
| **Normale de l&#39;espace monde** | Changez la vue des paramètres en [paramètres de Normale de l&#39;espace monde](../../../bakers-settings/world-space-normals/world-space-normals.md). |
| **ID** | Modifiez la vue des paramètres sur les [paramètres de couleur](../../../bakers-settings/color-map-from-mesh/color-map-from-mesh.md). |
| **Ambient occlusion** | Modifiez la vue des paramètres sur les [paramètres d&#39;Ambient occlusion](../../../bakers-settings/ambient-occlusion-from/ambient-occlusion-from-mesh.md). |
| **Courbure** | Changez la vue des paramètres en [paramètres de Courbure](../../../bakers-settings/curvature/curvature.md). |
| **Position** | Modifiez la vue des paramètres sur les [paramètres de position](../../../bakers-settings/position/position.md). |
| **Thickness** | Changez la vue des paramètres en [paramètres de Thickness](../../../bakers-settings/thickness-map-from-mesh/thickness-map-from-mesh.md). |
| **Height** | Modifiez la vue des paramètres sur les [paramètres d&#39;Height](../../../bakers-settings/height-map-from-mesh/height-map-from-mesh.md). |
| **Bents normals** | Modifiez la vue des paramètres sur les [paramètres de Bents normals](../../../bakers-settings/bent-normals-from-mesh/bent-normals-from-mesh.md). |
| **Opacité** | Modifiez la vue des paramètres sur les [paramètres d&#39;opacité](../../../bakers-settings/opacity-mask-from-mesh/opacity-mask-from-mesh.md). |

### Paramètres

![](../../../assets/sp-baking-params.png)

Cette partie de la fenêtre affiche les différents paramètres de baking. Son contenu peut changer en fonction du baker actuellement sélectionné ou des paramètres courants.

Pour en savoir plus sur les paramètres de baker, consultez les [paramètres de Baker](../../../bakers-settings/bakers-settings.md).

### Message d’aide

![](../../../assets/sp-baking-help.png){width="500px"}

Cette partie de la fenêtre affiche les différentes info-bulles et le message d’aide liés aux paramètres. Déplacez la souris sur un paramètre pour lire son info-bulle ici.
