# Houdini

>[!NOTE]
>
> Substance in Houdini est développé par SideFX Labs.

Le module externe [Substance pour Houdini](https://www.sidefx.com/tutorials/sidefx-labs-substance-plugin/) vous permet de charger des fichiers SBAR (Substance Archive files) dans Houdini dans des COP. Cela vous permet d’enchaîner des nœuds de Substance, d’alimenter la sortie des graphiques de Substance à toutes les parties de Houdini (Terrains, Matières, Géométrie) et à de nombreux autres workflows. Le plug-in est géré par l’équipe de SideFX Labs.

## Instructions d’installation

Pour Houdini 17.5, le plugin est distribué avec le GameDevelopment Toolset\
[Instructions d’installation de GameDevelopment Toolset](https://www.sidefx.com/tutorials/game-dev-toolset-installation/)

Pour Houdini 18.0, le plug-in est distribué avec SideFX Labs.\
[Instructions d’installation de SideFX Labs](https://www.sidefx.com/tutorials/sidefx-labs-installation/)
