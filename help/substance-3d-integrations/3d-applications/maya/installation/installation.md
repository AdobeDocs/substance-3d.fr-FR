# Installation

Le plug-in Substance in Maya est également installé officiellement dans le programme d’installation de Maya 2022/2020. L’installation est activée par défaut.

>[!NOTE]
>
> **Maya 2022**
> 
> **Windows** : C:\Program Files\Allegorithmic\Adobe Substance 3D pour Maya\2022\
> **MacOS** : /Applications/Allegorithmic/Adobe Substance 3D for Maya/2022\
> **Linux** : /opt/Allegorithmic/Adobe Substance 3D for Maya/2022

>[!NOTE]
>
> **Maya 2020**
> 
> **Windows** : C:\Program Files\Allegorithmic\Adobe Substance 3D pour Maya\2020\
> **MacOS** : /Applications/Allegorithmic/Adobe Substance 3D for Maya/2020\
> **Linux** : /opt/Allegorithmic/Adobe Substance 3D for Maya/2020

En outre, le programme d&#39;installation des dernières versions du plug-in peut être téléchargé à partir de la page [Adobe Substance 3D pour Maya](https://substance3d.adobe.com/plugins/substance-in-maya/).
