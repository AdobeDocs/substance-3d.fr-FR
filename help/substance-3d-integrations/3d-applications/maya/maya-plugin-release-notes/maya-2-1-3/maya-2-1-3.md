# Maya 2.1.3

Publié le 17 juin 2020

Aujourd’hui, nous avons publié la version 2.1.3 du plug-in.

Version 2.1.3 :

* Le programme d’installation est maintenant signé avec SHA-256 sous Windows
* Tous les fichiers binaires du programme d’installation sont désormais signés sous Windows
* substance\_link.dll et substance\_portal\_cli.dll disposent désormais d’informations sur la version/description sous Windows
* Ajout d’une option de workflow pour la surface standard dans Maya 2020

Cette version est publiée pour Maya 2017, 2018, 2019 et 2020 sur Windows, Linux et Macos. Il est également disponible pour Maya LT 2018, 2019 et 2020 sur Windows et MacOS.
