# Maya 0,9,11

**Modifications Maya 2.0 :**\
**Stabilité** :

* Les attributs dynamiques du graphique sont désormais créés en mode natif, et non via le code de l’éditeur d’attributs
* Les nœuds de Substance peuvent être créés par lots lors de leur initialisation sans avoir besoin d’une entrée d’interface utilisateur
* L’éditeur d’attributs et l’éditeur de propriétés sont nettement plus stables
* Les performances de la mémoire se sont nettement améliorées, suffisamment pour activer les sorties 8k sur le moteur GPU
* Paramètres/préférences désormais enregistrés dans un fichier de configuration distinct qui peut être facilement modifié en dehors de Maya

**Script** :

* API de script puissante, avec toutes les opérations, de la saisie des informations d’entrée, de graphique et de sortie, au chargement des packages sbsar, à la modification du graphique et à l’exécution de toute opération prédéfinie dans le gestionnaire des paramètres prédéfinis
* Code d’interface utilisateur conçu pour utiliser les mêmes fonctions que l’API de script public

**Fonctionnalités de Substance** :\
**Prise en charge des paramètres prédéfinis :**

* Les paramètres prédéfinis intégrés définis dans le concepteur sont chargés dans le gestionnaire des paramètres prédéfinis
* Importation et exportation de fichiers sbsprs, y compris de plusieurs paramètres prédéfinis
* Gestionnaire des paramètres prédéfinis
* Prise en charge du moteur V7
* Fonctionne déjà avec le nouveau moteur de Substance à publier avec Designer 2019.1
* Les sorties numériques sont rendues en un attribut de sortie maya sur le
* Nœud Graph/Substance pouvant être connecté à d’autres nœuds dans l’hyperombre

**Système de workflow :**

* Nouveaux workflows pour Arnold, Renderman, VRay, Corona et plus encore
* Extensions de workflow personnalisées dans Python
* Inversez les scripts de workflow de la nuance hypertexte, configurez un workflow personnalisé une fois et enregistrez-le
* Utilisation d’un workflow avec des images interactives de Substance Painter

**Améliorations de l’interface utilisateur et de l’expérience utilisateur :**

* Fichier -> importer .sbsar crée un nœud substance
* Glissez-déposez des fichiers sbsar du navigateur de fichiers vers hypershade pour créer des nœuds substance 2
* Les attributs sont désormais mis en page en fonction des catégories définies dans Designer

**Autres améliorations :**

* Les entrées d’image fonctionnent désormais avec des nœuds procéduraux
* Peut désormais définir le taux d’échantillonnage pour les nœuds de procédure afin de pouvoir sous-échantillonner ou sur-échantillonner les entrées d’image de procédure
* Les nœuds de sortie affichent désormais les informations de sortie codées en Substance Designer
* Les nœuds de Substance/graphique peuvent désormais afficher des informations sur le graphique (auteur, etc.)
* Prise en charge des remplacements de calque, tels que les remplacements de connexion et les remplacements d’attribut
* Le cache sur disque choisit le type de fichier exr pour toutes les sorties HDR, qui sont des sorties avec des sorties flottantes 16 bits, 16 ou 32 bits
* Reflet de l’ancien plug-in
* Le chargement d’une scène avec le nouveau plug-in convertit les anciens nœuds de graphe et de sortie en nœuds Substance 2
