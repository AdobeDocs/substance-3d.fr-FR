# Maya 2.2.3

Liste des modifications :

* Prise en charge ajoutée d’Arnold 7.1.0/MtoA 5.1.0 pour Maya 2019, 2020 et 2022
* Ajout d’une nouvelle commande de script, « substanceNodeGetGraphMetadata », pour acquérir les métadonnées du graphe de Substance de données sous forme de chaîne XML dans le script
* L’interrogation d’un graphe hors limites dans les appels de script n’est plus crash
* Les plug-ins Arnold et MtoA sont désormais installés dans un répertoire à l’aide de délimiteurs « - » entre les numéros de version sémantiques
* Les paramètres des ressources de moteur sont désormais correctement respectés, ce qui permet de corriger une régression dans laquelle ils ont été ignorés.

1. 2.3 est publié pour
1. Maya 2017, 2018, 2019, 2020, 2022 et 2023 sur Linux, macOS et Windows
1. Maya LT 2018, 2019 et 2020 sur macOS et Windows
