# Maya 2.2.2

Liste des modifications :

* Substance 3D Remote Engine mis à jour vers la version 8.4.2
* Prise en charge ajoutée de Maya 2023
* Prise en charge ajoutée d’Arnold 7.1.0/MtoA 5.1.0 dans Maya 2023
* Le workflow Arnold utilisant l’option « Appliquer le workflow aux mappages » identifie désormais correctement le mappage « metalness » à partir du modèle Arnold de Painter
* Si vous appliquez un paramètre prédéfini, les listes déroulantes de résolution se mettent désormais correctement à jour
* La commande « substanceRunImageWorkflow » renvoie désormais le shader final créé
* La commande « substanceNodeApplyWorkflow » renvoie également le shader final créé
* La commande « substanceUtilityCreateAndLoad » renvoie désormais le substanceNode qu&#39;elle crée

1. 2.2 est publié pour Maya 2017, 2018, 2019, 2020, 2022 et 2023 sur Linux, macOS et Windows
