# Maya 2.1.7

Publié le 28 septembre 2020

Liste des modifications :

* Mise à niveau pour être compatible avec la Substance Engine v.8.0.3, prenant en charge les nouveaux nœuds ajoutés dans Designer 2020.2

Cette version est publiée pour Maya 2017, 2018, 2019 et 2020 sur Linux, MacOS et Windows, et Maya LT 2018, 2019 et 2020 sur MacOS et Windows
