# Utilisation des sorties

Vous pouvez activer/désactiver les sorties manuellement dans la section Sorties.

![](../../../assets/outputs-1.png){width="800px"}

Un cercle fermé indique que la sortie a été créée. Dans l’image ci-dessus, vous pouvez voir que la couleur de base a été créée. Étant donné que l’option Sorties du cache sur le disque était activée, une sortie de Substance de données a été créée, ainsi qu’un nœud de fichier Maya. Le nœud de fichier lit la texture mise en cache sur le disque et est automatiquement mis à jour lorsque la Substance Engine traite les textures. Cliquez à nouveau sur le cercle fermé pour désactiver la sortie et supprimer les nœuds.

![](../../../assets/enabled-3.png)

Cliquez sur l’icône en forme de lunette pour sélectionner la sortie de Substance ou le nœud de fichier. Si le nœud de fichier a été créé, il sera sélectionné lorsque vous cliquerez sur l’icône de lunettes. Si un nœud de fichier n’est pas présent, la sortie de la Substance de données sera sélectionnée. Cela vous permet de naviguer rapidement vers un nœud de sortie ou de fichier. *\*Conseil : appuyez sur la touche F pour cadrer le nœud sélectionné dans l’éditeur de nœuds. C&#39;est pratique lorsque vous avez de nombreuses sorties et que vous devez trouver un nœud de fichier spécifique.*
