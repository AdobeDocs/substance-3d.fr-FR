# Utilisation du plug-in Substance

Le plug-in Substance se trouve dans le menu Plug-ins Cinema 4D.

![](../../../assets/cinema-4d-1.png){width="500px"}

## Charger la ressource...

Utilisez ceci pour charger les ressources de Substance dans votre scène. Seules les archives de Substance de données (.sbsar) peuvent être chargées. Si le Gestionnaire d’actifs de Substance de données n’est pas déjà affiché, il s’ouvre automatiquement lors de l’importation réussie de la Substance de données. Cette commande se trouve également dans le Gestionnaire d’actifs de Substance de données.

Lors de l’importation, vous pouvez être invité à copier la Substance dans le dossier de votre projet.

![](../../../assets/cinema-4d-2.png){width="500px"}

* Si vous répondez « Non », un chemin absolu vers la Substance sera stocké dans votre scène.
* Si vous répondez « Oui », la Substance sera copiée dans le sous-dossier tex de votre projet et dans votre scène, elle sera référencée par nom de fichier uniquement.

Cette invite n’apparaît qu’une seule fois par importation (par exemple, lors du glisser-déposer de plusieurs Substances à partir de l’Explorateur ou du Finder).
