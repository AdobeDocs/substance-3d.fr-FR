# Configuration

## Conditions requises

Un Cinema 4D R16 ou supérieur est requis. Toutes les versions du produit, sauf Cinema 4D Lite, sont prises en charge.

Les fichiers de Substances peuvent être créés avec [Substance Designer](https://www.allegorithmic.com/products/substance-designer).

## Installation

## Windows

1. Le Cinema 4D ne doit pas être en cours d’exécution pendant l’installation.
1. Exécutez le pack d’installation automatique.
1. Sélectionnez / vérifiez le dossier de destination. Il doit s’agir du dossier dans lequel Cinema4D a été installé, et non du sous-dossier des plug-ins.
1. Cliquez sur Installer.
1. Une fois l’installation terminée, vous aurez la possibilité de lancer le Cinema 4D.

## MAC OS X

1. Le Cinema 4D ne doit pas être en cours d’exécution pendant l’installation.
1. Déposez le fichier cld dans le dossier des plug-ins Cinema 4D.
1. Commencez le Cinema 4D comme d’habitude.
