# Utilisation des références

## Utilisation des références

Les matériaux de Substance peuvent être utilisés avec des scènes référencées. Toutefois, si vous devez désactiver une sortie pour une Substance dans une scène référencée, vous devrez supprimer manuellement les sorties. Il suffit de décocher la sortie sur les propriétés de la Substance pour ne pas supprimer les sorties des Substances référencées lors de l&#39;utilisation des préférences de référencement par défaut de MODO.\
Pour permettre à la matière de Substance référencée de supprimer ses propres sorties généréesPour supprimer manuellement les sorties, vous devez d’abord modifier les remplacements de référence pour la scène. Accédez à Elément > Références > Modifier les remplacements de référence et définissez les suppressions sur « Si autorisé par l&#39;élément ». Cela vous permettra de supprimer manuellement les sorties de Substance\
à partir de l’arborescence du nuanceur et du navigateur d’éléments pour toute scène ouverte ou créée après cette modification.

Reportez-vous à la documentation MODO pour plus d’informations sur les remplacements de référence.\
<http://modo.docs.thefoundry.co.uk/modo/801/help/pages/modointerface/ImportReference.html>
