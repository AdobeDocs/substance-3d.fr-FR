# Installation de Modo

Pour installer le plug-in, faites simplement glisser le fichier LPK dans MODO. Si vous n’avez pas installé de kit ou de pack de contenu MODO, une boîte de dialogue vous demandant de créer les dossiers appropriés peut s’afficher. Une fois le kit installé, un bouton de Substance apparaît en haut à droite de l&#39;interface utilisateur MODO.
