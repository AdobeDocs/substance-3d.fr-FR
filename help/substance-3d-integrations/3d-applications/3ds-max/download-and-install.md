# Téléchargement et installation

La dernière version du module externe est distribuée en mode natif par Autodesk avec la dernière version compatible de 3ds Max. Si vous avez besoin d’une version spécifique pour une ancienne version, veuillez trouver les liens de téléchargement ci-dessous.

* **Téléchargement pour Autodesk 3ds Max 2027:** <https://www.adobe.com/go/substance3d-3dsmax-win-latest>
* **Téléchargement pour Autodesk 3dsMax 2026:** <https://www.adobe.com/go/substance3d-3dsmax-win-2026>
* **Téléchargement pour Autodesk 3dsMax 2025:** <https://www.adobe.com/go/substance3d-3dsmax-win-2025>
* **Télécharger pour Autodesk 3dsMax 2024** (module externe version 3.1.0.) : <https://www.adobe.com/go/substance3d-3dsmax-win-2024>
