# Utilisation des workflows dans 3ds Max

Le module externe Substance in 3ds Max contient des workflows pour la création automatique d’un réseau de nuanceurs prenant en charge les systèmes de rendu. Les workflows de rendu se trouvent dans le menu Substance.

![](../../../assets/workflows-3.png)

Pour utiliser un flux de travail, sélectionnez le nœud de Substance dans l&#39;éditeur de matériaux, puis choisissez le flux de travail dans le menu Substance.

![](../../../assets/max-workflow.gif)
