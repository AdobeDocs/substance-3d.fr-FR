# 3ds Max 2.3.4

Publié le 16 juin 2020

1. Version 3.4 :

* Ajout d’une option de workflow pour le shader PBR (Spec/Gloss) pour 3ds Max 2021
* Ajout d’une option de workflow pour le shader PBR (Metal/Rough) pour 3ds Max 2021
* Les scripts de workflow n’échouent plus lors du déplacement de nœuds entre différentes vues dans le PME
* La définition d’un chemin relatif dans le suivi des actifs fonctionne désormais
* Si une sortie attendue par un script de workflow est manquante, elle est désormais consignée dans la console
* Ajout de la boîte de dialogue À propos, contenant des informations sur le plug-in, ainsi que les bibliothèques utilisées.
* La boîte de dialogue À propos comporte un bouton Copier dans le presse-papiers, comme Substance Painter, Substance dans Maya ou le Lanceur de Substances, permettant d’enregistrer les informations de diagnostic.

Cette version est publiée pour 3ds Max 2018, 2019, 2020 et 2021.
