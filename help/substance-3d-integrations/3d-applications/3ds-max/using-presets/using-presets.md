# Utilisation des paramètres prédéfinis

Les fichiers de Substance peuvent contenir des fichiers de paramètres prédéfinis incorporés. Si une Substance comporte un fichier de paramètres prédéfinis incorporé, celui-ci s’affiche dans la fenêtre Paramètres prédéfinis de Substance. Vous pouvez également créer vos propres paramètres prédéfinis en fonction des paramètres que vous choisissez pour les Paramètres de Substance.

![](../../../assets/max9.png)

1. Créer un paramètre prédéfini crée un nouveau paramètre prédéfini en fonction des paramètres que vous avez définis pour la Substance dans 3ds Max.
1. Importer la préconfiguration importe un fichier de préconfiguration (.sbsprs).
1. Enregistrer la préconfiguration enregistre les valeurs de paramètre pour la préconfiguration actuellement sélectionnée.
1. Exporter la préconfiguration sélectionnée exportera la préconfiguration dans un fichier de préconfiguration (.sbsprs).
1. Supprimer tous les paramètres prédéfinis supprime les paramètres prédéfinis de la liste des paramètres prédéfinis.
1. Supprimer le paramètre prédéfini sélectionné ne supprime que le paramètre prédéfini sélectionné.
