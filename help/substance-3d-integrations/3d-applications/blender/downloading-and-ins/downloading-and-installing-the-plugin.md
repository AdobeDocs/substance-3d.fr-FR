# Téléchargement et installation du plug-in

## Télécharger

Pour télécharger le plug-in, visitez [Substance 3D dans Blender](https://substance3d.adobe.com/plugins/substance-in-blender/). Cliquez sur **Télécharger le plug-in** pour lancer le téléchargement.

Vous pouvez également obtenir la dernière version directement à partir des liens ci-dessous.

Il existe deux fichiers .zip distincts à télécharger et à installer :

* Module complémentaire Substance 3D pour Blender ([téléchargement unique pour toutes les plateformes](https://www.adobe.com/go/substance3d-blender-multi-latest))
* Outils d&#39;intégration Substance 3D (télécharger les versions [Windows](https://www.adobe.com/go/substance3d-integrationtools-win-latest), [Mac](https://www.adobe.com/go/substance3d-integrationtools-mac-latest) ou [Linux](https://www.adobe.com/go/substance3d-integrationtools-lin-latest))

>[!WARNING]
>
> **Pour les utilisateurs de Mac :** *Les utilisateurs doivent désactiver « ouvrir les fichiers sécurisés après le téléchargement » s’ils téléchargent le plug-in avec Safari.*
>
> Par défaut, le navigateur web Safari décompresse les fichiers .zip téléchargés, qui doivent rester compressés pour l’installation. Pour empêcher le fichier de se décompresser, mettez à jour les préférences de Safari pour ne pas ouvrir les fichiers « sûrs » après le téléchargement.
>
> 1. Ouvrir Safari
> 1. Cliquez sur **Préférences**
> 1. Sous l&#39;onglet Général, décochez l&#39;option **Ouvrir les fichiers « sûrs » après le téléchargement.**

## Étapes d’installation

### Première installation

1. Téléchargez les fichiers .zip du plug-in à partir de la page de version préliminaire Adobe.
1. Ouvrir le mélangeur (v. 3.0 ou version ultérieure).
1. Dans la barre de navigation supérieure, sélectionnez Modifier, puis Préférences. Sélectionnez ensuite l’onglet Modules complémentaires.
1. Cliquez sur le bouton **Installer**.
1. Dans l’explorateur de fichiers, recherchez le dossier vers lequel les fichiers .zip ont été téléchargés
1. Sélectionnez le fichier Substance 3DInBlender.zip et cliquez sur le bouton **Installer le module complémentaire**.
1. Dans la section Modules complémentaires, cochez la case pour activer le module complémentaire et cliquez sur la flèche déroulante pour développer la section.
1. Vous serez invité à installer les outils d’intégration. Cliquez sur **Installer à partir du disque** pour sélectionner **Substance 3DIntegrationTools.zip** et cliquez sur le bouton **Installer les outils**.\
   S&#39;ils n&#39;ont pas été téléchargés précédemment, cliquez sur **Télécharger** pour ouvrir la page de version préliminaire Adobe dans votre navigateur et télécharger les outils, puis utilisez **Installer à partir du disque** pour les installer.
1. Le module complémentaire est maintenant prêt à l’emploi !

### Mise à jour du plug-in et des outils

1. Téléchargez la dernière version à partir des liens ci-dessus.
1. Utilisez le bouton **Désinstaller les outils** pour supprimer les outils d&#39;intégration Substance 3D.
1. Utilisez le bouton **Supprimer** pour désinstaller le module complémentaire
1. Fermer et redémarrer le mélangeur
1. Dans la barre de navigation supérieure, sélectionnez Modifier, puis Préférences. Sélectionnez ensuite l’onglet Modules complémentaires.
1. Cliquez sur le bouton **Installer**.
1. Dans l’explorateur de fichiers, localisez les fichiers ZIP nouvellement téléchargés.
1. Sélectionnez le fichier Substance 3DInBlender.zip et cliquez sur le bouton **Installer** le module complémentaire.
1. Dans la section Modules complémentaires, cochez la case pour activer le module complémentaire et cliquez sur la flèche déroulante pour développer la section.
1. Vous serez invité à installer les outils d’intégration. Cliquez sur **Installer à partir du disque** pour sélectionner le fichier Substance 3DIntegrationTools.zip, puis cliquez sur le bouton **Installer les outils**.\
   S&#39;ils n&#39;ont pas été téléchargés précédemment, cliquez sur **Télécharger** pour ouvrir la page de version préliminaire Adobe dans votre navigateur et télécharger les outils, puis utilisez **Installer à partir du disque** pour les installer.
1. Le module complémentaire est maintenant prêt à l’emploi !

### Mise à jour de composants individuels

Lors de la mise à jour du module complémentaire uniquement :

1. Dans les préférences du module complémentaire, utilisez le bouton **Supprimer** pour désinstaller le module complémentaire.
1. Redémarrer le mélangeur
1. Accédez à nouveau aux préférences du module complémentaire et utilisez le bouton **Installer** pour charger la nouvelle version du plug-in. Les outils d’intégration précédemment chargés resteront.

Lors de la mise à jour des outils d’intégration uniquement :

1. Dans les préférences du module complémentaire, utilisez le bouton **Mettre à jour les outils** pour charger la version la plus récente des outils d&#39;intégration. Le module complémentaire précédemment utilisé sera conservé.
1. Redémarrez Blender pour que les modifications prennent effet.
