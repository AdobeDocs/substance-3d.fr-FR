# Désinstallation du module complémentaire

Pour désinstaller le module complémentaire, accédez à Modifier > Préférences > Modules complémentaires et développez la section correspondante.

1. Supprimez d&#39;abord les outils d&#39;intégration avec le bouton **Désinstaller les outils**.
1. Supprimez ensuite les fichiers du module complémentaire avec le bouton **Supprimer**

>[!NOTE]
>
> Si les outils d’intégration de Substance doivent être supprimés manuellement, supprimez le dossier Substance 3DIntegrationTools du répertoire ci-dessous
> 
> * **Windows** : C:\Users\(nom d’utilisateur)\AppData\Roaming\Adobe
> * **Mac** : /Users/(nom d’utilisateur)/Library/Application Support/Adobe/Substance 3DIntegrationTools
> * **Linux** : /home/(nom d&#39;utilisateur)/Adobe/Substance 3DIntegrationTools
