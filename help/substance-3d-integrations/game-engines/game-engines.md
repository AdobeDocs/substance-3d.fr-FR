# Moteurs de jeu

Vous pouvez importer un fichier de Substance (.sbsar) dans la plupart des principaux moteurs via le module externe de Substance.

* <b>Unity</b> intègre le plug-in Substance en mode natif pour le cycle de publication 2017. Pour Unity 2018 et les versions ultérieures, le plug-in de Substance est disponible dans le [Unity Asset Store](https://assetstore.unity.com/packages/tools/utilities/substance-in-unity-110555).
* Le plug-in <b>Unreal Engine</b> se trouve sur le [Marché irréel](https://accounts.unrealengine.com/logout?redirectUrl=https%3A%2F%2Fwww.unrealengine.com%2Fmarketplace%2Fsubstance-plugin).
* Le plug-in <b>Lumberyard</b> est intégré en mode natif.
* Le plug-in <b>CRYENGINE</b> est intégré et géré en mode natif par Crytek. Pour plus d&#39;informations, consultez la [documentation CRYENGINE Substance](https://docs.cryengine.com/pages/viewpage.action?pageId=44968527)
