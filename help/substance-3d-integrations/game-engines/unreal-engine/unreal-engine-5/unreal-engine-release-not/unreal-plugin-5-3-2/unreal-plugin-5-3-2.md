# Unreal plugin 5.3.2

Publié le 4 décembre 2023

<b>Fixe</b>

* Correction d’un problème de compatibilité en raison duquel le plug-in de Substance ne fonctionnait pas sur Mac pour Unreal Engine 5.3.
* Correction d’un problème en raison duquel la désélection d’un canal Matériau dans le plug-in de Substance pour Unreal Engine ne provoquait plus de blocage.
* Correction d’un problème en raison duquel le matériau « stone-arc.sbars » dans le plug-in affichait uniquement les options « Taille de sortie » sous la section Entrée, au lieu d’afficher une gamme complète de propriétés de matériau modifiables.
* Correction d’un problème de changement de couleur dans le plug-in Substance, en raison duquel les matériaux importés affichaient des normales incorrectes décalées en rouge et des cartes de base de couleur incorrecte.
* Correction d’un problème de plantage dans le plug-in de Substance où l’utilisation de « Réimporter » sur un fichier .sbsar entraînait le blocage de l’éditeur.
* Amélioration de la validation des entrées dans le plug-in de Substance pour empêcher les entrées hors limites et non valides dans les champs de propriétés de matériau clés. »
* Correction d’un bug en raison duquel la création d’une deuxième instance de graphique dans le plug-in Substance supprimait tous les paramètres prédéfinis précédemment chargés. »
* Correction d’un problème en raison duquel la réimportation d’une instance Substance Factory supprimait tous les paramètres prédéfinis existants.
