# Image d’entrée de Substance - UE4

La Substance peut être créée avec des entrées permettant de fournir une image à traiter dans le matériau. Cela vous permet de créer des matériaux modulaires qui peuvent utiliser des données ou des motifs de maillage cuits comme entrée pour modifier ou conformer le matériau à la ressource. Pour utiliser une texture comme entrée de substance, elle doit être importée dans UE4 en tant que texture d&#39;entrée de Substance.

1. Importez la texture dans l’Explorateur de contenu. Pour le format, choisissez Substance Image Entrée (jpg, tga, jpeg).
1. Cette texture peut désormais être utilisée avec une entrée de Substance.
