# Plug-in irréel 4.26.0.1

Il s’agit d’une version pour la compatibilité UE4.26.

Problèmes connus :

* Impossible de télécharger des actifs de la source dans UE4 de manière cohérente. La solution consiste à télécharger à partir du [site web Substance Source](https://source.substance3d.com/) et à importer manuellement les actifs.
