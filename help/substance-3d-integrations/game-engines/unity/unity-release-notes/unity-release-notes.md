# Notes de mise à jour d’Unity

Nous prenons actuellement en charge le plug-in Adobe Substance 3D pour Unity à partir de la version 3.0.0 d’Unity. Les versions précédentes du plug-in Substance 3D pour les anciennes versions d’Unity seront bientôt obsolètes.

**Les versions d’Unity de 2.2.0 à 2.6.0 seront bientôt obsolètes.**
