# Unity 2.5.4

Publié le 9 décembre 2020

Fixe :

* Impossible de générer des applications iOS compatibles avec les codes de bits lorsque des matériaux de Substance sont inclus dans un projet Unity

Problèmes connus :

* Impossible de télécharger des actifs de la source dans Unity de manière cohérente. La solution consiste à télécharger à partir du [site web Substance Source](https://source.substance3d.com/) et à importer manuellement les actifs.
* Unity 2020.2 et versions ultérieures ne sont actuellement pas pris en charge
