# Unité 2.4.3

Publié en décembre 2019

Correctifs de bogues :

* Fixe : carte des normales inversée
* Correction : problème de démarrage de la position verticale dans l’inspecteur
* Correction : gestion de la barre de défilement dans la section « Textures générées » du graphique de l’inspecteur. Déboguer le texte nettoyé
* Correction : erreur d’orthographe « PC, Max et Linux » sur le texte de survol de la résolution de la plate-forme
* Correction : erreur lors de la modification des paramètres de résolution de plateforme et du clic sur le bouton de navigation Matière
* Correction : le packing HDRP ne gère pas correctement l’authentification unique. La couche verte de la carte du masque est noire
* Fixe : (Régression, Mac uniquement) Les sorties/Substances numériques sans cartes de texture valides se bloquent sur Unity.
* Correction : blocage lors de la modification de paramètres et du clic sur une autre instance d’une Substance.
* Correction : erreur d’interface graphique lorsque vous cliquez sur l’objet de Substance principal, puis sur le graphique de Substance (depuis 2019.2 ou version ultérieure uniquement)
* Correction : erreur Unity 2019.3 lors de l’importation de fichiers sbsar
* Correction : la fonction Duplicate() n’effectue pas le rendu complet de la Substance, sauf s’il existe un appel de rendu dans le script
