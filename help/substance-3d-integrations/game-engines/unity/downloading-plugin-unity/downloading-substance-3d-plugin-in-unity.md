# Téléchargement du plug-in Substance 3D dans Unity

## Magasin de ressources

Adobe Substance 3D pour Unity est disponible dans le [magasin de ressources Unity](https://assetstore.unity.com/packages/tools/utilities/substance-3d-for-unity-beta-213208). Le plug-in est ajouté à votre projet dans le dossier Ressources.

## gestionnaire de modules

Une fois que vous avez ajouté et téléchargé le plug-in via Asset Store, vous pouvez ensuite accéder au plug-in à l’aide du gestionnaire de modules (Unity 2020.3.27x et versions ultérieures) sous **Mes actifs**.

![](https://helpx-prod.scene7.com/is/image/HelpxProd/screen-shot-2022-03-29-at-10-45-20-am?$png$&jpegSize=300&wid=1920)

### Cache du gestionnaire de modules

Le cache du magasin d’actifs peut avoir une incidence sur la version qui apparaît disponible dans le gestionnaire de modules/Mes actifs. Si vous n’obtenez pas la dernière version, vous devrez peut-être supprimer le cache du magasin de ressources.\
