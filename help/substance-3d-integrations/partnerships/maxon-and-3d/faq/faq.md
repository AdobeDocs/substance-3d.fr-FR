# FAQ sur Adobe Substance 3D et Maxon One

+++Comment accéder à la collection Adobe Substance 3D ?
Une fois votre achat de Maxon One + the Adobe Substance 3D Collection terminé, vous recevrez un code promo qui vous permettra d’utiliser la collection Substance 3D sur le site web d’Adobe avec votre Adobe ID. Si vous n’avez pas d’Adobe ID, vous devrez créer un compte et vous connecter pour utiliser le coupon.

+++

+++Comment puis-je utiliser le code promo de la collection Adobe Substance 3D ?
Pour utiliser le code promo Collection Substance 3D Adobe :

* Accéder à <https://redeem.adobe.com>.

* Connectez-vous ou créez un compte Adobe.

* Saisissez le code d’échange qui vous a été envoyé et cliquez sur « Échanger le code ».

* Cliquez sur « Ajouter un mode de paiement » pour le renouvellement automatique ou sur « Me le rappeler plus tard ».

* Cliquez sur « Commencer ».

+++

+++Combien de temps le code de coupon est-il valide ?
Le code de coupon est limité à un usage unique et est valable un an à compter de la date d&#39;achat.

+++

+++Je suis déjà utilisateur de Maxon One. Puis-je effectuer la mise à niveau vers l’offre groupée ?
L’offre groupée est un achat unique et la tarification spéciale n’est disponible que pour les nouveaux abonnements.

+++

+++Qu’est-ce qui est inclus dans le lot ?
L’offre comprend un abonnement d’un an à Maxon One et à la collection Adobe Substance 3D.

* Maxon One comprend :
  * Cinema 4D

  * Red Giant

  * La bibliothèque complète de ressources Capsule

+++

+++Comment renouveler mon abonnement après la première année ?
Votre abonnement à Maxon One sera automatiquement renouvelé pour une autre année au prix normal (1199 USD par an ou équivalent régional).

La Collection Substance 3D d’Adobe se renouvellera automatiquement uniquement si vous saisissez une carte de crédit valide lors de l’utilisation de votre code promo ou si vous ajoutez une carte de crédit à votre page de gestion de compte sur account.adobe.com avant la date d’expiration de la période d’abonnement.

[Comparez les formules d’abonnement Adobe](https://www.adobe.com/creativecloud/plans.html) pour connaître le tarif de la formule individuelle Adobe Substance 3D Collection, abonnement annuel payé à l’avance.

+++

+++Pendant combien de temps cette offre groupée sera-t-elle disponible ?
Cette offre spéciale est disponible pour une durée limitée.

+++

+++Ce lot est-il le signe d’une collaboration plus étroite entre Adobe Substance 3D et Maxon ?
Maxon et Adobe s’engagent à travailler ensemble pour améliorer le processus créatif pour les utilisateurs du monde entier. Grâce à cette offre groupée, ils continuent de démontrer leur engagement à fournir des outils qui permettent aux artistes de transcender les frontières, d&#39;explorer de nouveaux domaines et de créer des visuels qui trouvent un écho auprès du public.
