# Arnold

Le matériau Surface standard d&#39;Arnold 5 prend désormais en charge le workflow métallique. Vous pouvez exporter les canaux du document à partir de Substance Painter lorsque vous utilisez le shader métallique par défaut ou simplement utiliser les sorties de flux de travaux métallique du plug-in Substance à partir d’un matériau Substance.

* Couleur de base
* Rugosité
* Métallique
