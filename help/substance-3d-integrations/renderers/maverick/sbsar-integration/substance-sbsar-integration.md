# Intégration SBSAR de Substance

**Vous pouvez** **facilement**&#x200B;**importer** **des fichiers SBSAR** **créés** **en Substance Designer ou en Substance** **Alchemist** **à** **non-conformistes &#x200B;**&#x200B;**suivant**&#x200B;**l&#39;une** **de** **ces** **2** **méthodes**&#x200B;**:**

**Méthode** **1:**

1. Utilisez l’icône SBSAR et sélectionnez votre fichier SBSAR.

   ![](../../../assets/maverickrender-sbsar-icon.jpg)
1. Dans la boîte de dialogue Importer, vous pouvez définir certains paramètres de matière :

   ![](../../../assets/maverickrender-sbsar-import-1.jpg)
1. Si vous continuez, votre matière apparaît dans le panneau Matières, prête à être utilisée dans votre scène :

   ![](../../../assets/maverickrender-sbsar-drop.jpg)

   **Méthode** **2**&#x200B;**:**
1. Déposez simplement votre fichier SBSAR de l’Explorateur Windows vers n’importe quel objet de la scène. Vous pouvez également déposer des fichiers SBSAR dans le panneau Matériau.
1. Dans la boîte de dialogue Importer, vous pouvez définir certains paramètres de matière :

   ![](../../../assets/maverickrender-sbsar-import-1.jpg)
1. La matière sera appliquée à l’objet que vous avez déposé.

   **Conseils et astuces :**
1. Vous pouvez modifier les paramètres SBSAR en sélectionnant le nœud de Substance dans le panneau Matières ou en cliquant sur l’un des bouchons de canal du matériau.
1. Nous vous recommandons de modifier le matériau à une résolution de 512 ou 1024 pour rendre la modification plus fluide. Pour les rendus finaux, vous pouvez augmenter la résolution à 2 048 ou 4 096.
1. Si vous souhaitez utiliser le même SBSAR mais avec des paramètres différents sur un autre objet de la scène, dupliquez-le et appliquez-le au nouvel objet. Maverick créera automatiquement une nouvelle matière que vous pourrez modifier indépendamment.
1. Si vous avez plusieurs SBSAR sur la scène, vous pouvez utiliser le bouton « Définir comme résolution globale » dans l&#39;un d&#39;eux pour contrôler la résolution de tous à la fois.

   ![](../../../assets/maverickrender-sbsar-resolution.jpg)
1. Maverick comprend 10 matières et SBSAR que vous pouvez retrouver dans la bibliothèque d’Ombrages sous les dossiers Matières/Substance et Mappages/SBSAR :

   ![](../../../assets/maverickrender-sbsar-library.jpg)
1. Si vous voulez rendre vos propres SBSAR disponibles pour Maverick, créez un sous-dossier pour les placer dans

   « C:\Users\User\Documents\RandomControl\library\Shading\My Maps ».

   Ensuite, vous pouvez simplement les déposer sur vos objets afin que Maverick puisse créer le matériau d&#39;enveloppe correspondant.

   Vous pouvez voir une vidéo d’introduction pour SBSAR dans Maverick ici : <https://youtu.be/HosZOoMRfcM>
