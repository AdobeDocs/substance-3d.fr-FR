# Thea

Thea Substance ™ Converter vous permet de créer un matériau Thea à partir d&#39;un Fichier sbsar Substance ™. Vous pouvez utiliser les paramètres exportés avec le fichier Substance ™ pour modifier l’aspect des textures et voir l’aperçu du matériau créé avant d’enregistrer le résultat final.

Thea Substance ™ Converter vous permet de créer un matériau Thea à partir d&#39;un Fichier sbsar Substance ™. Vous pouvez utiliser les paramètres exportés avec le fichier de Substance de données pour modifier l’aspect des textures de données et voir l’aperçu du matériau créé avant d’enregistrer le résultat final. Vous pouvez utiliser n&#39;importe quel Fichier sbsar, mais avec un matériau Substance ™ basé sur le modèle PBR Métallique/Rugosité, vous vous assurez que le matériau Thea créé sera également basé sur un modèle physique.

Veuillez consulter les documents de rendu Thea pour plus d’informations. [Convertisseur de Substance de rendu Thea](http://thearender.media/docs/fr/thea-substance-converter/menu)
